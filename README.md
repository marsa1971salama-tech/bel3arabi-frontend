# تطبيق بالعربي (Mobile App)

تطبيق React Native (بواسطة Expo) لمنصة تعليم اللغة العربية — يعمل على Android وiOS من نفس الكود.
يتصل بالـ Backend الموجود في مجلد/ملف `bel3arabi-backend` المُرسل سابقاً.

## التشغيل للتجربة (بدون حاجة لـ Xcode أو Android Studio)
1. ثبّت تطبيق **Expo Go** من App Store أو Google Play على جوالك
2. على جهاز الكمبيوتر:
   ```bash
   npm install
   npm start
   ```
3. امسح رمز QR الذي يظهر باستخدام تطبيق Expo Go — التطبيق يفتح مباشرة على جوالك

## قبل التجربة: اربطه بالـ Backend
افتح `src/api.js` وغيّر:
```js
export const API_BASE_URL = "https://YOUR-BACKEND-DOMAIN.com";
```
إلى الرابط الفعلي بعد ما تنشر الـ Backend (على Railway/Render/أي استضافة). أثناء التطوير المحلي فقط،
يمكن استخدام عنوان الشبكة المحلية لجهازك (مثال: `http://192.168.1.5:4000`) بدل `localhost`
لأن الجوال جهاز منفصل عن الكمبيوتر.

## الشاشات الجاهزة
- تسجيل الدخول / إنشاء حساب (طالب أو معلّم)
- تصفّح المعلّمين مع فلترة (غير الناطقين بالعربية / أطفال عرب)
- ملف المعلّم + الحجز (اختيار موعد وباقة أسعار)
- حجوزاتي (وسم الحصة كمكتملة + تقييم بالنجوم)
- تقديم كمعلّم (مع ملاحظات ذكاء اصطناعي فورية على الطلب)

## قبل النشر الفعلي على المتاجر
- استبدل `API_BASE_URL` بالرابط النهائي
- أضف أيقونة وشاشة splash حقيقية في `app.json`
- راجع سياسات Apple/Google الخاصة بالمدفوعات داخل التطبيق قبل دمج Stripe
- استخدم `eas build` (أداة Expo الرسمية) لبناء نسخة قابلة للنشر على App Store وGoogle Play

## ما ينقص هذا الإصدار (يحتاج مطوّر لإكماله)
- شاشة إدارة كاملة (حالياً مقترَح أن تبقى لوحة الإدارة ويب منفصلة)
- الدفع الفعلي (Stripe) — الحجز الحالي لا يحصّل مالاً حقيقياً
- مكالمة الفيديو المدمجة
- إشعارات Push
